# QuickNotes

A simple notes app where you can add categorised notes, search them, and keep them after refreshing the page.

[paste your GitHub repository URL here]

## Features

- Add notes with a category (Personal, Work or Study)
- Each category has its own coloured left border
- Validation: empty notes and notes over 200 characters are rejected with an error message
- Delete individual notes
- Note counter ("You have no notes yet.", "You have 1 note.", "You have N notes.")
- Notes are saved in localStorage, so they stay after a refresh
- Live search that ignores upper/lower case, with a "No notes match your search." message
- Responsive layout: the form stacks vertically on screens 600px or narrower

## Technologies

- HTML
- CSS (Flexbox, media queries)
- JavaScript (DOM manipulation, localStorage)

Download or clone the repository and open `index.html` in a browser. No installation needed.
